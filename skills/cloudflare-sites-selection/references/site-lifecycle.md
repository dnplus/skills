# Sites 生命週期盤點

以可用 Sites 工具唯讀列出使用者有權查看的站點，完成分頁並讀取候選站點詳情。工具缺失、權限不足或分頁未完成時，說明盤點範圍與缺口；不要將不可見當成不存在。日常盤點不需要索取寫入憑證或下載所有原始碼。

逐站記錄：用途、ID／連結、受眾、正式站標記、自訂網域、已知引用與依賴、版本／更新時間、可取得的使用證據、資料與復原需求。盤點報告留在使用者授權的私人位置；取不到的值寫「未知」，不要補零。

查核引用與依賴，例如文件連結、嵌入頁、外部書籤的使用者確認、webhook、排程、MCP 或整合入口。同名或相似畫面只表示候選重複，不足以證明能合併。未更新不等於未使用；缺流量資料不等於零流量。

| 分類 | 判準與建議 |
| --- | --- |
| 保留 | 正在使用、被引用、有依賴、承載重要資料；正式公開站與自訂網域站預設保護。 |
| 合併 | 用途及受眾重疊且有明確承接站；列出資料、權限、連結與依賴如何承接，僅建議方案。 |
| 待確認 | 用途、使用情況、擁有者、資料或依賴未知，或證據互相矛盾。 |
| 建議刪除 | 已確認失去用途的測試／過期站，無已知使用或依賴，資料已確認可丟棄或可復原；列出仍須確認的條件。 |

保護訊號優先於清理訊號；正式公開站、自訂網域站與有引用的舊站不因年齡而成為刪除候選。每列輸出分類、理由、證據日期、未知項與下一步；數量多時先列需要使用者決定的少數候選。

執行刪除、下架、合併寫入或改權限前，另行取得涵蓋確切站點、動作與影響的適當確認，並核對依賴、資料備份／匯出與復原限制。既有「定期檢查、建議刪除」授權不包含這些操作。遇到拒絕停止該動作；結果不明先查現況，不盲目重試。

## 定期檢查

只有使用者要求才建立排程。先以唯讀操作確認排程執行環境能存取所需 Sites，再使用可用的正式自動化工具；確認頻率、時區、私人報告位置，並在結果成功後才宣稱已排程。工具或存取不可用時交付盤點規則並標示未排程，不聲稱會在背景持續監控。

排程提示保留唯讀、未知流量、保護站點與需確認的界線，例如：「盤點可存取的 Sites，與上次報告比較，提出保留／合併／待確認／建議刪除清單及依據。無資料標未知，保護正式公開站、自訂網域及已被引用站點。僅產出私人建議報告，不改動站點。」避免在提示中存放憑證或不必要的私人清單。
